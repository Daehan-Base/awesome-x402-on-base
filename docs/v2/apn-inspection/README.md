# 결제 전에 도구의 권한 경계 확인하기: APN 메타데이터 예시

> **작성일 / 확인일**: 2026-10-27
> **확인 대상**: APN v0.5.76, Apple Silicon macOS, Node.js 24.19.0. 아래 네 가지 메타데이터 명령만 실측했습니다.

## 개요

Web2에서 청구서를 읽는 권한과 회사 카드로 결제하는 권한은 다릅니다. x402 도구도 이름에 `inspect`, `prepare`, `approve`가 있다는 사실만으로 실제 권한을 알 수 없습니다. 이 문서는 외부 로컬 도구인 Agent Payment Node(APN)의 메타데이터를 읽고, Base 결제 실험 전에 무엇을 별도로 확인해야 하는지 설명합니다.

APN은 이 프로젝트나 Base/Coinbase의 공식 SDK가 아닙니다. Nuanu AI의 APN 소개를 돕는 AI가 작성한 자료이며 독립적인 추천이나 제작자의 실사용 후기가 아닙니다. 결제 성공, x402 버전 호환성, Base Sepolia 지원을 검증한 예제가 아닙니다.

## 코드 위치와 사전 요구사항

| 구분 | 위치 / 조건 |
|------|-------------|
| 로컬 | 소유자가 이미 설치하고 출처를 확인한 `apn` 실행 파일. 이 저장소의 `external/x402/`에는 APN이 포함되지 않습니다. |
| 원본 | [nuanu-ai/agent-payment-node](https://github.com/nuanu-ai/agent-payment-node) |
| 공식 릴리스 | [v0.5.76](https://github.com/nuanu-ai/agent-payment-node/releases/tag/v0.5.76) |
| 지원 범위 | Apple Silicon macOS, Node.js 24. Windows/Linux/Intel/Docker 지원을 가정하지 않습니다. |

일반 설치 안내는 위 공식 저장소에 있습니다. 이 문서의 확인 범위에 Homebrew 설치 검증은 포함되지 않습니다. 알 수 없는 실행 파일, 설치되지 않은 호스트, 다른 버전이면 여기서 멈추고 소유자와 출처를 먼저 확인합니다. 에이전트가 설치·업그레이드·MCP 등록을 자동 실행하지 않습니다.

## 설정 변경 없이 메타데이터 읽기

```bash
apn --version
apn --help
apn help --json
apn mcp config
```

관찰한 버전은 `0.5.76`입니다. `--help`는 텍스트이며 `help --json`의 스키마는 `apn.command-manifest.v2`입니다. 명령 목록의 경로, 효과 분류, 승인 분류, 옵션 제약과 복구 안내를 함께 읽습니다. 매니페스트는 약 280 KB이므로 에이전트 대화에 통째로 넣지 말고 필요한 명령 부분만 검토합니다. 메타데이터가 존재한다는 사실은 그 제약이 모든 실행 경로에서 강제됨을 입증하지 않습니다.

`mcp config`에서 관찰한 값은 다음과 같습니다.

```json
{"schema_version":"apn.mcp-launch.v1","transport":"stdio","command":"apn","args":["mcp","serve"]}
```

이는 실행 설명자입니다. 호스팅된 HTTP 주소, 소유자 동의, 지갑 연결, Cursor/Claude 연결 성공을 뜻하지 않습니다. 이 문서는 서버 실행이나 클라이언트 설정 변경을 요청하지 않습니다.

## Base/x402 실험 전에 나눠서 확인할 것

1. **조사**: 어떤 명령이 읽기, 로컬 상태 변경, 네트워크 요청, 자금 효과를 선언하는지 구분합니다. 이름만 보고 판단하지 않습니다.
2. **준비**: prepare 결과나 레시트가 견적, 승인, 서명, 전송 또는 정산 중 무엇을 입증하는지 확인합니다. 준비 완료를 결제 완료로 표시하지 않습니다.
3. **소유자 단계**: APN의 직접 송금/EVM 승인은 전경 터미널 단계로 분리됩니다. MCP의 `apn_foreground_handoff`는 사람이 실행할 명령을 반환합니다. 반환된 명령을 에이전트가 대신 실행해서 동의를 우회하지 않습니다.
4. **별도 정책 경로**: 일부 Solana x402 결제는 소유자가 별도로 허용한 정책에서 실행할 수 있습니다. 따라서 MCP 전체가 읽기 전용이거나 모든 서명마다 새 승인이 필요하다고 일반화하면 안 됩니다. Solana 정책을 Base에 적용하지 않습니다.
5. **실험 네트워크**: 이 저장소의 개발 규칙은 Base Sepolia만 허용합니다. 여기서는 APN의 Base Sepolia 지원을 확인하지 않았습니다. 지원 증거가 없다면 APN으로 자금 실험을 시작하지 말고, 메인넷으로 대체하지 않습니다. 프로토콜 학습은 아래 이 저장소의 기존 문서에서 시작합니다.

## 보안과 검증 범위

- 개인 키, 복구 구문, 실제 결제 승인, `.env` 값을 문서·프롬프트·로그·스크린샷에 넣지 않습니다. 개발용과 운영용 지갑은 분리합니다.
- 이 확인에는 지갑 생성/연결, Keychain 접근, 실제 잔액 조회, 서명·송금, 클라이언트 연동, 보안 감사가 포함되지 않습니다. 명령의 종료 코드 0은 실제 결제나 OS 샌드박스 검증이 아닙니다.
- MIT는 소프트웨어 라이선스입니다. 네트워크/제공자 수수료나 결제 자금이 무료라는 의미가 아닙니다.
- 실제 사용 전에 지원 체인·자산·받는 사람·접속 대상·한도와 런타임 권한을 별도로 검토해야 합니다. 취약점은 [APN SECURITY.md](https://github.com/nuanu-ai/agent-payment-node/blob/main/SECURITY.md)의 비공개 경로로 보고하며 비밀값을 보내지 않습니다.
